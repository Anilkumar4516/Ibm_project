# IBM Applied Data Science (ADS) Project — Future Sales Prediction

This repository contains milestone presentation decks for an academic / IBM Applied Data Science project titled **"7214 - Future Sales Prediction"**, completed with team member B. Anil Kumar.

---

## 📁 Repository Contents

| File | Format | Description / Phase Focus |
| :--- | :--- | :--- |
| `ADS_phase1.pptx` | PowerPoint Presentation | **Phase 1:** Project overview, team member details, problem definition, and standard data science lifecycle methodology. |
| `ADS_phase 2.pptx` | PowerPoint Presentation | **Phase 2:** Problem framing and preliminary data exploration structure. |
| `ADS_Phase3.pptx` | PowerPoint Presentation | **Phase 3:** Exploratory Data Analysis (EDA), inspecting advertising channel features (`TV`, `Radio`, `Newspaper`), target variable (`Sales`), and data type/null-value checks. |
| `ADS_Phase4.odp` | OpenDocument Presentation | **Phase 4:** Intermediate visual analysis and model evaluation considerations. |
| `ADS_Phase5-1.potx` | PowerPoint Template / Presentation | **Phase 5:** Feature scaling and normalization, model evaluation metrics, regression analysis using Plotly scatter and OLS trendlines, and business conclusion on sales forecasting. |
